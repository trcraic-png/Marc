Activación Autodesk APS

  1. Crear una aplicación Autodesk APS tipo servidor y obtener Client ID / Client Secret.
  2. Configurar APS_CLIENT_ID, APS_CLIENT_SECRET y APS_ACTIVITY_ID como variables de entorno del servidor.
  3. La Activity script-first ya está preparada por el backend. Al conectar APS se crea automáticamente.
    4. \n
  4. El código fuente del AppBundle 3D está preparado en el repositorio para la segunda etapa.
  5. Usar “Probar conexión Autodesk” y verificar que el engine configurado esté disponible.
  6. Al generar DWG, el backend envía un WorkItem y recibe el resultado para visualizar/exportar.
